# Gourav Bose — Portfolio

A responsive personal portfolio for Gourav Bose, built as a single-page experience with a refined dark palette, glass effects, subtle motion, and a lightweight Three.js scene.

## Run locally
Open `index.html` in a browser. Google Fonts and the Three.js background are loaded from external CDNs; the page content remains readable if the 3D scene is unavailable.

## Customize
Update the profile, education, experience, skills, and contact details in `index.html` to keep the portfolio current.
